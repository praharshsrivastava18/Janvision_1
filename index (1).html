What is simulatedEight agency operators work day shifts from their home subnets. Any row's "Compromise" button gives that credential to an attacker on 203.0.113.0/24 who starts quiet and ramps up across all four record files.

How scoring works hereThis page uses a distance model fitted to 3,000 simulated normal windows. The notebook version uses an Isolation Forest and an autoencoder with the same features: volume, rows, exports, off-hours use, subnet drift, table breadth.

What the ledger provesEvery query is hash-chained and added to a Merkle tree. Signed checkpoints are kept outside the database, so a rewritten history no longer matches. The last entries after the newest checkpoint can still be cut off unnoticed, which is why checkpoints are frequent.
